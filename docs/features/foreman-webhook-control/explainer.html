The Foreman can wire the outside world into Crew.

Webhook control becomes one more bounded graph-building power: useful enough to build an autonomous workflow, constrained enough that names, races, and audit logs cannot become capability leaks.

One guarded path

1 · Intent crew webhook create

The managed CLI resolves the live caller, not a caller-supplied name.

2 · Authority

Guard checks the active Foreman flag, immutable owner GUID, and live hook quota.

3 · Graph

An unblessed source node connects only to an owned agent through finite limits.

4 · Delivery

An external POST enters the existing durable message path. The human can review and bless it.

The safety rules in plain language

Ownership is a GUID, never a name A replacement called “planner” does not inherit the original planner's hooks.
Revocation does not break integrations The public hook remains live; management falls back to the human operator.
The last quota slot is serialized Concurrent creates cannot both commit after observing the same stale count.
Audit history is not a secret store Nested tokens, hashes, URLs, templates, and credentials are redacted before persistence.
