Crew · feature system v3

One feature.
One durable page.

Every feature keeps its description, technical contract, diagrams, exact verification, screenshots, and videos in one repository-owned HTML page. Binary proof lives beside it in assets/.

Canonical shape

docs/features/<feature-id>/
├── index.html
└── assets/
    ├── terminal.png
    └── flow.mp4

Agent workflow

  1. Run python3 scripts/new_feature.py.
  2. Complete the page and embedded manifest.
  3. Capture actual candidate commands and results.
  4. Put sanitized media in assets/.
  5. Run scripts/validate_feature_docs.py.
